## 📋 1. Project Overview & Value Proposition

**SolSherlock AI** is an autonomous, async Telegram bot that performs deep on-chain financial audits and risk assessments for any Solana token. 

### Why is this needed?
Solana retail traders often fall victim to low liquidity traps, pump-and-dumps, or wash trading because checking on-chain metrics is slow and manually intensive. SolSherlock AI resolves this by providing a unified, instant risk assessment directly inside Telegram within seconds.

---

## 🛠 2. Core Architecture & Integrations

The project is built using a fully asynchronous model with modular, loose coupling of three main services:

```mermaid
graph TD
    A[Telegram User] -->|Sends Token Address| B[Bot Core - aiogram v3]
    B -->|Fetch On-Chain Data| C[Solana Client - DexScreener API]
    C -->|Return Raw Metrics| B
    B -->|Format Prompt & Send Telemetry| D[AI Analyst - Gemini 2.5 Flash API]
    D -->|Generate Rich Audit Report| B
    B -->|Send Formatted Report + Risk Score| A
```

### Components:
1. **`bot.py` (Telegram Interface):** Powered by `aiogram v3` for asynchronous event polling. Validates addresses via base58 regex.
2. **`solana_client.py` (Data Layer):** Pulls real-time liquidity depth, FDV, volume, price changes (5m/1h/6h/24h), and transaction counts from DEX pools using the DexScreener API.
3. **`ai_analyst.py` (AI Brain):** Formats telemetry and queries the Google Gemini 2.5 Flash API using custom financial expert prompts to compute a 0-100 Risk Score.
4. **`config.py` & `.env` (Security):** Safely loads environment configurations to protect sensitive API keys.
